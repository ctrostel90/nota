1. INTRODUCTION                                                  *notes-intro*

Notes are markdown files below a directory you choose (|notes-config-dir|),
optionally in subfolders. New notes open as unsaved buffers filled from a
template; nothing is written, and no folder is created, until you save.

Requires Neovim 0.11+. |:NotesGrep| needs ripgrep (`rg`). Everything else is
pure Lua and works the same on Windows and Linux.

==============================================================================
2. SETUP                                                         *notes-setup*

>lua
    require("notes").setup({ dir = "~/notes" })
<
Commands work without |notes-setup|, using the defaults. Keymaps, the
follow-link keys and completion integration are enabled by `setup()`.

==============================================================================
3. COMMANDS                                                   *notes-commands*

:NotesNew [folder/name]                                            *:NotesNew*
    Create a note from the `default` template. Without an argument, prompts
    for the name. An empty name uses `timestamp_format`; a trailing `/`
    (`work/`) puts a timestamped note in that folder. Tab completes folders.
    An existing note with the same name is opened instead.

:NotesNewFrom {template} [folder/name]                         *:NotesNewFrom*
    Create a note from {template} (see |notes-templates|), prompting for the
    name if omitted and for the template's fields. Without arguments, pick a
    template first. Tab completes template names.

:NotesToday                                                      *:NotesToday*
    Open or create today's note from the `daily` template.

:NotesFind                                                        *:NotesFind*
    Fuzzy find notes, newest first. Each entry shows the note's tags when
    |notes-config-find_tags| is on, so `#meeting #plc` narrows to notes with
    both tags.

:NotesGrep                                                        *:NotesGrep*
    Search the contents of all notes with ripgrep: live grep in telescope,
    fzf-lua or snacks; with the `select` picker, prompts for a pattern and
    fills the |quickfix| list.

:NotesTags [tag ...] [-tag ...]                                   *:NotesTags*
    Without arguments, pick a tag (with note counts), then a note. With
    arguments, list notes that have every given tag and none of the
    `-`-prefixed ones. A leading `#` is optional. Each word tab-completes.

:NotesBacklinks                                              *:NotesBacklinks*
    Pick from the notes that link to the current note.

==============================================================================
4. KEYMAPS                                                     *notes-keymaps*

Global, set by `setup()` (|notes-config-keymaps|):

    <leader>nn    |:NotesNew|
    <leader>nd    |:NotesToday|
    <leader>nf    |:NotesFind|
    <leader>ng    |:NotesGrep|
    <leader>n#    |:NotesTags|
    <leader>nb    |:NotesBacklinks|

Buffer-local in notes (|notes-config-links|):

    <CR>, gf      Follow the [[link]] under the cursor. Off a link, the key
                  does what it normally does.

5. CONFIGURATION                                                *notes-config*

Defaults:
>lua
    require("notes").setup({
      dir = "~/notes",
      templates = {
        default = "# {{title}}\n\n{{cursor}}",
        daily = {
          template = "# {{date}}\n\n{{cursor}}",
          dir = "daily",
          name = "{{date:%Y-%m-%d}}",
        },
      },
      template_dir = nil,
      date_format = "%Y-%m-%d",
      time_format = "%H:%M",
      timestamp_format = "%Y%m%d-%H%M%S",
      picker = "auto",
      find_tags = true,
      links = { keys = { "<CR>", "gf" }, confirm_create = true },
      completion = { omnifunc = true },
      start_insert = true,
      keymaps = {
        new = "<leader>nn", today = "<leader>nd", find = "<leader>nf",
        grep = "<leader>ng", tags = "<leader>n#", backlinks = "<leader>nb",
      },
    })
<
dir                                                         *notes-config-dir*
    Root folder for notes. `~` and environment variables are expanded.

templates                                             *notes-config-templates*
    Templates by name, see |notes-templates|. Merged per template with the
    built-in `default` and `daily`.

template_dir                                       *notes-config-template_dir*
    Folder whose `<name>.md` files become templates named `<name>`.

date_format, time_format                            *notes-config-date_format*
    |strftime()| formats for `{{date}}` and `{{time}}`.

timestamp_format                               *notes-config-timestamp_format*
    Filename used when a note's name comes out empty.

picker                                                   *notes-config-picker*
    "auto", "telescope", "fzf-lua", "snacks" or "select". See |notes-pickers|.

find_tags                                             *notes-config-find_tags*
    Show tags in note lists so the fuzzy query can match them.

links                                                     *notes-config-links*
    `keys`: buffer-local keys that follow links; `{}` disables them.
    `confirm_create`: ask before creating the note a dangling link points to.

completion                                           *notes-config-completion*
    `omnifunc`: set 'omnifunc' in notes. See |notes-completion|.

start_insert                                       *notes-config-start_insert*
    Start insert mode at `{{cursor}}` in new notes.

keymaps                                                 *notes-config-keymaps*
    Global keys; set one to `false` to disable it.

6. TEMPLATES                                                 *notes-templates*

A template is a string, a path to a template file, a function(ctx) returning
a string or a list of lines, or a table:

    template   content (string, file path or function); defaults to
               `template_dir/<name>.md`, then the `default` template
    dir        folder relative to the notes root
    name       filename pattern without `.md` (default `{{slug}}`)
    fields     list of `{ name = "x", prompt = "X: " }` or `"x"`, prompted
               after the note name

>lua
    templates = {
      customer = {
        dir = "meetings/customers",
        name = "{{date:%Y-%m-%d}}-{{customer}}-{{slug}}",
        fields = { "customer" },
      },
    }
<
Placeholders, in content and filenames:

    {{title}}        name as typed; date and time when empty
    {{slug}}         filename-safe name
    {{date}}         |notes-config-date_format|
    {{time}}         |notes-config-date_format|
    {{date:<fmt>}}   any |strftime()| format (also {{time:<fmt>}})
    {{<field>}}      a prompted field
    {{cursor}}       cursor position (content only)

In filenames values are slugified, and separators left by empty values are
dropped. A folder typed in the name replaces the template's `dir`; a leading
`/` means the notes root.

==============================================================================
7. TAGS                                                           *notes-tags*

A tag is `#` at the start of a line or after whitespace, followed by letters
(including non-ASCII), digits, `_`, `-` or `/`, with at least one non-digit.
Tags are case-insensitive. Nested tags count for their parents: `#work/plc`
is also found under `work`.

Not tags: headings (`# Title`), `C#`, `page#anchor`, `(#section)`, `#123`,
and anything in fenced or inline code.

Tags are read from saved files. The index re-reads a file only when its
modification time or size changes.

==============================================================================
8. LINKS                                                         *notes-links*

    [[name]]            note named `name.md` anywhere in the tree
    [[folder/name]]     disambiguates between notes with the same name
    [[name|alias]]      alias is ignored for resolution
    [[name#Heading]]    opens the note at that heading
    [[#Heading]]        heading in the current note
    [[/name]]           only `name.md` at the notes root

Names are compared slugified, so `[[Meeting Notes]]` finds `meeting-notes.md`.
An exact path match wins over a filename match. Several matches open a
picker; none offers to create the note (as an unsaved buffer). Links to other
files (`![[image.png]]`) and links in code are ignored.

==============================================================================
9. COMPLETION                                               *notes-completion*

In notes, `#` completes tags (by use, with counts) and `[[` completes notes
(by path or `# Title`). Accepting a link inserts the shortest name that still
resolves to that note and closes the brackets.

blink.cmp: >lua
    sources = {
      default = { "lsp", "path", "snippets", "notes" },
      providers = {
        notes = { name = "Notes", module = "notes.completion.blink" },
      },
    },
<
nvim-cmp: `setup()` registers the source; add `{ name = "notes" }` to your
sources.

omnifunc: |i_CTRL-X_CTRL-O| in notes when |notes-config-completion| has
`omnifunc = true`.

==============================================================================
10. PICKERS                                                    *notes-pickers*

With `picker = "auto"` the first installed of telescope.nvim, fzf-lua and
snacks.nvim is used, falling back to |vim.ui.select()|. Note pickers show a
file preview. In telescope, each space-separated word of the query must
match, in any order.
